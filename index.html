What You Can Paste

No strict template required — mix and match formats freely.

  • Numbered phases & phase names e.g., PHASE 0 — Setup, Phase 1: Login, ## Phase 2, or 0. Setup
  • Phase descriptions Introductory goals, environment notes, and instructions preserved without turning into checkboxes
  • Subheadings & testing categories e.g., Desktop:, Mobile View:, or Markdown subheadings like ### Validation
  • Bullet-point & checkbox test cases Supports -, *, •, ☐, and [ ] list items
  • Numbered test cases Ordered checks like 1. Test valid credentials.
  • Existing test IDs & priorities Preserves identifiers like TEST-001 — ... or AUTH-001: ...
  • Final regression & release checklists End-of-plan sign-off and release readiness sections

Validation & Schema Integrity Rules

  • Schema Validation: Checks for valid Qavora structure and verifies supported schemaVersion: 1.
  • Input Sanitization: All textual fields are safely sanitized to protect against script execution.
  • Integrity Verification: Missing arrays (e.g. phases, suites, test cases, executions, defects) are automatically normalized to safe empty sets.

Flexible Import Strategies

  • Merge Imported Data: Safely adds imported projects alongside your existing workspace. Conflicting project IDs are re-assigned unique IDs while preserving internal test case and defect references.
  • Replace Existing Workspace: Restores an exact backup state. An automatic snapshot of your current data is saved to memory first, allowing instant 1-click rollback if needed.

100% Client-Side Privacy Architecture

Qavora is engineered with an offline-first, client-authoritative design. All application state is stored locally within your web browser's isolated localStorage engine.

  • Zero Network Telemetry: No tracking scripts, server databases, or cloud analytics monitor your test plans.
  • Proprietary QA Confidentiality: Internal bug tickets, reproduction steps, and test credentials never traverse the internet.

LocalStorage Quota & Best Practices

Modern browsers allocate approximately 5 MB to 10 MB of UTF-16 storage per origin. Because Qavora utilizes compact, normalized JSON data, a standard workspace can hold thousands of test cases and execution runs.

  • Regular Backups: Download a full workspace backup weekly or prior to milestone releases.
  • Device Portability: To move your QA repository to another laptop or browser, simply export your backup and restore it.
